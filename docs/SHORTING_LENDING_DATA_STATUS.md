# 공매도·주식대차 데이터 연동 상태

최종 점검: 2026-11-01 (KST)

## 1. 공식 출처에서 확인한 사항

공식 데이터셋: [금융위원회_주식대차정보 (15059612)](https://www.data.go.kr/data/15059612/openapi.do)

공공데이터포털의 데이터셋 설명에서 확인되는 내용:

- REST API, JSON/XML 제공
- 6개 오퍼레이션: 주식대차종목순위, 주식종목별대차거래현황, 월별대차거래현황, 주식업종별참여현황, 내외국인대차잔고비교, 내외국인대차거래량
- 필수 파라미터 안내상 업종별 참여현황만 `basDt`, `isinCd`가 필수이며 나머지 오퍼레이션은 별도 필수 파라미터가 없다고 기재
- 기준일자 `basDt` 미지정 시 최신 기준일로 설정된다고 기재
- 데이터는 실시간이 아니며 기준일 다음 영업일 13시 이후 갱신
- 이용허락은 공공누리 제2유형(출처표시 + 상업적 이용금지). 상업적 이용은 원천 제공기관 한국예탁결제원과 목적·범위에 따른 정보이용계약 필요. 문의: portal@ksd.or.kr
- 포털 상세 페이지에 참고문서 `금융위원회_주식대차정보_활용자가이드.docx`가 표시됨

## 2. 아직 공식적으로 검증하지 못한 명세

현재 실행 환경에서는 공식 활용자가이드 DOCX 원문과 오퍼레이션별 OpenAPI 상세 명세(요청 URL, 각 요청 파라미터, 응답 필드 설명, 페이지네이션 및 기간 조회 제한)를 내려받거나 열람하지 못했습니다. 따라서 다음 항목은 구현에 사용하지 않았습니다.

- 오퍼레이션의 실제 요청 URL/path
- `beginBasDt` / `endBasDt` 기간 필터의 해당 오퍼레이션 지원 여부
- `numOfRows`, `pageNo`, 응답 포맷 파라미터의 정확한 명세
- 2026-05-01 이후 과거 데이터 조회 가능 범위 및 보존 시작일
- 응답 필드별 단위·의미·널 허용 여부

독립적인 공개 코드 저장소에는 다음 후보 명칭과 필드가 기록되어 있으나, 이는 금융위원회 또는 공공데이터포털의 공식 명세가 아니므로 **교차 조사용 단서일 뿐 구현 근거로 채택하지 않았습니다**.

- 서비스 후보: `GetStocLendBorrInfoService_V2`
- 종목별 현황 후보: `getStItemLendAndBorrStatu_V2`
- 종목별 순위 후보: `getStLendAndBorrItemRank_V2`
- 종목별 현황 후보 필드: `basDt`, `isinCd`, `isinCdNm`, `lnbCclStckCnt`, `lnbRdptStckCnt`, `lnbRmanStckCnt`
- 위 필드의 단위 및 각 필터·기간·페이지 파라미터는 공식 가이드로 재확인해야 함

## 3. 저장소 변경

- `.github/workflows/shorting-backtest.yml`에 `KRX_LENDING_API_KEY: ${{ secrets.KRX_LENDING_API_KEY }}` 연결
- workflow 실행 시 키 값은 출력하지 않고 Secret 설정 여부만 검사
- 기존 KRX 공매도 데이터 형식·저장 경로는 보존. 단, CD007 잠금 및 로그인 응답 비정상(JSON 아님) 감지 시 전체 수집을 즉시 중단하도록 재시도 안전장치 추가
- KRX 인증 실패 분류 함수의 단위 테스트 4건 추가. 테스트 실행은 아직 GitHub Actions에서 확인되지 않음
- 공식 명세가 확인되지 않아 대차 수집 스크립트, 대차 원자료 CSV 및 공매도·대차 비교파일은 아직 생성하지 않음

## 4. 기존 공매도 데이터의 마지막 확인 상태

저장소에 커밋된 기존 수집 요약(2026-10-30 기준):

- 요청 기간: 2026-05-01 ~ 2026-10-31
- 공매도 거래량: 192,860행
- 공매도 잔고: 186,892행
- 전종목 주가: 201,282행
- 기록된 요청: 917건, 실패: 426건
- 직전 점검 산출물의 실제 조회일 범위는 공매도 거래량 2026-05-04~2026-08-07, 공매도 잔고 2026-05-04~2026-08-06, 주가 2026-05-01~2026-08-06
- 따라서 요청 기간 전체를 수집한 상태가 아니며, 2026-08-07 이후 공백이 존재
- KRX 인증 응답의 JSON 파싱 실패가 관측되었음. 원인을 비밀번호 오류로 단정하지 않으며, CD007 잠금 징후가 있으면 추가 로그인 시도를 중단해야 함
